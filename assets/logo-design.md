# 基维斯 (Jeeves) Logo 设计方案

## 品牌定位

- **名称**: 基维斯 / Jeeves
- **定位**: 开源家庭AI管家
- **调性**: 专业、智能、温暖、可靠
- **受众**: 科技爱好者、极客、智能家居用户

---

## 设计方向

### 方案A: 字母J + 神经网络

**概念**: 字母J变形为智能管家的抽象形象，融入神经网络节点元素

```
    ╭───╮
    │ ◉ ◉   ← 眼睛（两点代表AI感知）
    │  ▽    ← 微笑（温暖友好）
    ╰─│─╯
      │     ← 领带/领结（管家身份）
     ╱ ╲    ← 底座（稳定可靠）
```

**特点**:
- 极简线条，易于识别
- J字母融入管家形象
- 科技与人文的结合

---

### 方案B: 房屋 + 大脑

**概念**: 家的轮廓 + AI大脑的结合

```
       /\
      /  \         ← 屋顶
     / AI \        ← AI核心
    ┌──────┐
    │ ◯◯◯ │       ← 窗户（代表设备节点）
    │  ██  │       ← 门（入口/控制）
    └──────┘
```

**特点**:
- 直观传达"智能家居"概念
- 大脑元素强调AI能力
- 稳重可靠的感觉

---

### 方案C: 管家剪影 + 光环

**概念**: 英式管家剪影，头部有AI光环

```
       ⭐          ← AI光环/智能标识
      /||\
     ┌────┐
     │ ◉◉ │       ← 管家面部
     │ ▽  │
     ╰┬┬┬╯
      │││        ← 燕尾服轮廓
     ┌┴┴┴┐
     │    │
     └────┘
```

**特点**:
- 英式管家形象（致敬Jeeves文化原型）
- AI光环强调智能属性
- 有辨识度，易于传播

---

### 方案D: 极简几何

**概念**: 几何图形构成，现代科技感

```
    ╭────────╮
    │  ╭──╮  │
    │  │◯◯│  │     ← 抽象头部/控制面板
    │  ╰──╯  │
    │ ══════ │     ← 分割线（管家腰带）
    │        │
    ╰────────╯
       │  │
       ╰──╯        ← 底座
```

**特点**:
- 极简现代风格
- 适合App图标
- 可动态化（加载动画）

## 配色方案

### 主色
| 颜色 | 色值 | 用途 |
|------|------|------|
| 深海蓝 | #1E3A5F | 主色，专业、可靠 |
| 科技青 | #00D4AA | 强调色，AI、智能 |
| 温暖白 | #F8F9FA | 背景，干净、明亮 |

### 辅助色
| 颜色 | 色值 | 用途 |
|------|------|------|
| 深灰 | #2D3436 | 文字 |
| 浅灰 | #DFE6E9 | 分割线 |
| 警告橙 | #FF7675 | 异常状态 |

---

## 推荐选择

**首选方案A**（字母J+神经网络）:
- 最简洁，最易传播
- 可扩展性强（线条版、填充版、动画版）
- 适合各种尺寸（favicon到广告牌）

**备选方案C**（管家剪影）:
- 品牌故事感强
- 适合走IP路线
- 有情感连接
